How uMessage smart replies workمنطق پاسخ‌های هوشمند uMessage

Everything runs on the phone. No internet, no AI service, no message leaves the device. It is rules and word lists, not a language model.همه‌چیز روی خود گوشی اجرا می‌شود. بدون اینترنت، بدون سرویس هوش مصنوعی، هیچ پیامی از دستگاه بیرون نمی‌رود. این سیستم قانون و فهرست کلمات است، نه مدل زبانی.

1. The whole path of one incoming message۱. مسیر کامل یک پیام ورودی

0Incoming SMS arrivesپیامک جدید می‌رسد
↓
1Gate: is a reply allowed at all?دروازه: اصلاً اجازهٔ پیشنهاد هست؟
  • Smart replies switch is ON (default ON)
  • One person chat, not a group, not MMS
  • Sender is a saved contact, not a service name (bank, shop)
  • Newest message, received less than 6 hours ago
  • Short: at most 10 words and 160 characters
  • No link, no run of 4+ digits (codes), no money amount
  • Chat is not hidden
  • کلید پاسخ هوشمند روشن باشد (پیش‌فرض روشن)
  • گفتگوی یک‌نفره، نه گروه، نه MMS
  • فرستنده مخاطب ذخیره‌شده باشد، نه نام سرویس (بانک، فروشگاه)
  • تازه‌ترین پیام و کمتر از ۶ ساعت از دریافتش گذشته باشد
  • کوتاه: حداکثر ۱۰ کلمه و ۱۶۰ حرف
  • بدون لینک، بدون عدد ۴ رقمی یا بیشتر (کد)، بدون مبلغ پول
  • گفتگو مخفی نباشد
↓ passقبول
2Layer 1: phrase tables (short fixed phrases)لایه ۱: جدول عبارت‌ها (عبارت‌های کوتاه ثابت)

Text is cleaned (case, accents, Arabic look-alike letters, ZWNJ, digits). The script is detected (Latin, Arabic/Persian, Chinese, Japanese, Korean, Thai, Hindi, Bengali, Cyrillic) so a Persian message is never read with English words. Then it is matched against intents: thanks, ok, on my way, good morning, sorry, ...

متن پاک‌سازی می‌شود (حروف بزرگ/کوچک، اعراب، حروف شبیه عربی، نیم‌فاصله، ارقام). خط نوشتار تشخیص داده می‌شود (لاتین، فارسی/عربی، چینی، ژاپنی، کره‌ای، تایلندی، هندی، بنگالی، سیریلیک) تا پیام فارسی هرگز با کلمات انگلیسی خوانده نشود. بعد با «نیت‌ها» تطبیق می‌خورد: ممنون، باشه، دارم میام، صبح بخیر، ببخشید، ...

↓ found? yes → step 4  |  no ↓پیدا شد؟ بله ← مرحلهٔ ۴  |  نه ↓
3Layer 2: question engine (understands what is asked)لایه ۲: موتور سؤال (می‌فهمد چه پرسیده شده)

Runs only when layer 1 found nothing. Message must be a single question. Type is picked in this order: Choice → When → Where → Invite → Request → Yes/No. First cue that matches wins. Details in section 3.

فقط وقتی اجرا می‌شود که لایه ۱ چیزی پیدا نکرده باشد. پیام باید یک سؤال تنها باشد. نوع به این ترتیب انتخاب می‌شود: انتخابی ← زمان ← مکان ← دعوت ← درخواست ← بله/خیر. اولین نشانه‌ای که جور شود برنده است. جزئیات در بخش ۳.

↓ nothing found → no chips (a wrong chip is worse than none)چیزی پیدا نشد ← هیچ چیپی نشان داده نمی‌شود (چیپ غلط بدتر از بی‌چیپ است)
4Pick 3 replies and show themانتخاب ۳ پاسخ و نمایش
  • Replies come from a pool of 1–8 variants per intent; a seeded shuffle rotates them, so "Thanks", "Thank you", "Cheers" take turns
  • In the notification: as chips under the message (the Reply input choices)
  • In the thread: as chips above the message box
  • A tap sends the text at once, same SIM and same path as typing a reply
  • پاسخ‌ها از یک مجموعهٔ ۱ تا ۸ تایی برای هر نیت می‌آیند؛ ترتیب تصادفیِ دارای seed آن‌ها را می‌چرخاند، پس «ممنون»، «مرسی»، «دمت گرم» نوبتی می‌آیند
  • در نوتیفیکیشن: به شکل چیپ زیر پیام
  • در گفتگو: به شکل چیپ بالای کادر پیام
  • لمس چیپ بلافاصله ارسال می‌کند، با همان سیم‌کارت و همان مسیرِ تایپ دستی

2. Layer 1 in detail: phrase tables۲. جزئیات لایه ۱: جدول عبارت‌ها

DataدادهOne file per language: assets/smart_replies/<lang>.json. 20 languages.یک فایل برای هر زبان: assets/smart_replies/<lang>.json. ۲۰ زبان.
IntentنیتExact phrases and "contains" phrases, plus a reply pool of up to 8 texts (each at most 60 characters).عبارت‌های دقیق و «شامل»، به‌علاوهٔ مجموعهٔ پاسخ تا ۸ متن (هرکدام حداکثر ۶۰ حرف).
Filler and vetoحشو و وتوFillers ("please", "hey") are ignored. Veto words silence the match ("thanks, but no" is not a thanks).حشو («لطفاً»، «سلام») نادیده گرفته می‌شود. کلمات وتو تطبیق را خاموش می‌کنند («ممنون ولی نه» تشکر نیست).
Language tie-breakانتخاب زبانSame script, many languages (Latin): the app language wins ties.یک خط، چند زبان (لاتین): زبان برنامه تساوی را حل می‌کند.
ConfidenceاطمینانEach language has a minimum confidence. Below it: nothing is shown.هر زبان یک حداقل اطمینان دارد. کمتر از آن: چیزی نشان داده نمی‌شود.

3. Layer 2 in detail: the question engine۳. جزئیات لایه ۲: موتور سؤال

Message must end with a question mark (or start like a yes/no question). Two questions in one message give nothing.

پیام باید با علامت سؤال تمام شود (یا مثل سؤال بله/خیر شروع شود). دو سؤال در یک پیام = هیچ پیشنهادی.

Register: a formal sender (Persian "شما", German "Sie", French "vous", ...) gets formal chips; an informal one gets casual chips. Not answered: "why", "how much", "who", messages with links, codes, money.

رسمی/صمیمی: فرستندهٔ رسمی (مثلاً «شما» در فارسی) چیپ رسمی می‌گیرد و فرستندهٔ صمیمی چیپ صمیمی. پاسخ داده نمی‌شود: «چرا»، «چقدر»، «کی (چه کسی)»، پیام‌های دارای لینک، کد یا مبلغ.

4. Where the chips appear۴. چیپ‌ها کجا دیده می‌شوند

NotificationنوتیفیکیشنChips under the message, then Mark as read and Reply. Switch: Settings → Smart replies → "In notifications" (default ON). Hidden chats never get chips.چیپ‌ها زیر پیام، بعد «Mark as read» و «Reply». کلید: تنظیمات ← پاسخ هوشمند ← «در نوتیفیکیشن» (پیش‌فرض روشن). گفتگوهای مخفی هرگز چیپ نمی‌گیرند.
Thread screenصفحهٔ گفتگوChips above the message box, same gate and same tables.چیپ‌ها بالای کادر پیام، با همان دروازه و همان جدول‌ها.

5. Honest limits۵. محدودیت‌های صادقانه

  • Rules and word lists, not an AI. Odd or long messages get no chips, by design.
  • Tables for 18 languages are machine written and have no native review yet; English and Persian are the most careful.
  • No emoji chips today. Google Messages shows some (a smile, a sad face); adding them is possible: emoji replies for thanks, congrats, sad news.
  • Choice options are cut from the message words, so a long or odd phrase may give no chip.
  • قانون و فهرست کلمات است، نه هوش مصنوعی. پیام عجیب یا بلند عمداً چیپ نمی‌گیرد.
  • جدول ۱۸ زبان با ماشین نوشته شده و هنوز بازبینی بومی نشده؛ انگلیسی و فارسی با دقت بیشتری نوشته شده‌اند.
  • امروز چیپ ایموجی نداریم. Google Messages بعضی را نشان می‌دهد (لبخند، ناراحت)؛ اضافه‌کردنش شدنی است: ایموجی برای تشکر، تبریک، خبر ناراحت‌کننده.
  • گزینه‌های سؤال انتخابی از کلمات خود پیام بریده می‌شوند، پس عبارت بلند یا عجیب ممکن است چیپ نگیرد.
