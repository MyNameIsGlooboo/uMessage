```sh
xcode-select --install
```

```sh
[bundle exec] fastlane android test
```

Run the unit tests, lint and detekt

### android deploy

```sh
[bundle exec] fastlane android deploy
```

Build the signed gplay AAB and upload it with its metadata to the internal track of Google Play

### android metadata

```sh
[bundle exec] fastlane android metadata
```

Upload the Play Store listing (text, images, changelogs) without a new build
